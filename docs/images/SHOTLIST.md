# Screenshot shot list

Drop the files in this folder using exactly these names — the README already links to
them. PNG, and ideally all from the same spot with the same camera angle so the
comparison grids read as comparisons rather than a tour.

Delete this file once the images are in.

## Setup that makes them look right

Use **Preview time** (Sky section) to pin the hour rather than waiting for it, and the
**Weather** dropdown to force each condition rather than waiting for the cycle. Both
snap instantly, so all eight sky and weather shots can be taken without moving.

Turn the performance overlay off for every shot except its own.

A good vantage point is somewhere open with landmarks on the horizon — Falador
south wall, Lumbridge castle roof, or the Varrock square — so the sky takes up a
decent share of the frame and there is scenery to catch the light.

## The shots

| Filename | What it is | Settings |
|---|---|---|
| `hero.png` | The one that sells it. Whatever you think looks best. | Your pick |
| `sky-dawn.png` | Dawn sky | Preview time ≈ 360 (06:00) |
| `sky-midday.png` | Midday sky | Preview time ≈ 720 (12:00) |
| `sky-dusk.png` | Dusk sky | Preview time ≈ 1170 (19:30) |
| `sky-night.png` | Night, ideally with stars and aurora showing | Preview time ≈ 60 (01:00), full moon |
| `weather-rain.png` | Rain, wet ground | Weather = Rain |
| `weather-storm.png` | Storm — try to catch a lightning flash | Weather = Storm |
| `weather-snow.png` | Snow settled on the ground | Weather = Snow, wait for buildup |
| `weather-overcast.png` | Sealed grey deck, no sun | Weather = Overcast |
| `lighting-night.png` | Torchlit street at night | Night, dynamic lights up, somewhere with torches |
| `perf-overlay.png` | The overlay itself | Performance overlay on, all four sub-options |

## Optional, if you want them

A before/after pair is the single most convincing thing on a plugin page. Same spot,
same angle, `Preset = Default` and `Preset = Custom`. If you take those, name them
`compare-off.png` and `compare-on.png` and I will add a section for them.
